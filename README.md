# צ'אטבוט שירות לקוחות – חברת סלולר בישראל

## 1. התחום שנבחר
הבוט נבנה עבור מוקד **שירות לקוחות של חברת סלולר בישראל**. 
מאגר הידע (`dataset.json`) כולל 40 זוגות של שאלות ותשובות נפוצות במגוון נושאים: הצטרפות וניוד מספרים, הפעלת סים ו-eSIM, חבילות גלישה בארץ ובחו"ל, חשבוניות וחיובים, תמיכה טכנית, חסימת קו במקרה אובדן וניתוק מנוי.

## 2. אופן ההרצה וסדר התאים
הפרויקט מורכב מ-8 תאי קוד שיש להריץ לפי הסדר הכרונולוגי (באמצעות `Shift + Enter` בכל תא):

1. **תא 1 (התקנה):** התקנת הספריות הנדרשות (`cohere`, `numpy`, `gradio`). *(בסביבת ההרצה באתר הספריות מותקנות מראש)*.
2. **תא 2 (חיבור):** ייבוא הספריות, טעינת מפתח ה-API והגדרת מודל ה-Embedding (`embed-multilingual-v3.0`) ומודל השפה (`command-a-03-2025`).
3. **תא 3 (המאגר):** טעינת הקובץ `dataset.json` (שיש להעלות מראש לסביבת העבודה) וחילוץ רשימת השאלות.
4. **תא 4 (Embeddings):** הפיכת 40 השאלות שבמאגר לווקטורים בממד 1024.
5. **תא 5 (שמירת הווקטורים):** נרמול הווקטורים ושמירתם כמטריצה בקובץ `faq.npy`.
6. **תא 6 (שליפה):** הגדרת פונקציית `retrieve` לחישוב דמיון קוסינוס והרצת שאילתות בדיקה לצורך כיול סף הדמיון (`SCORE_THRESHOLD`).
7. **תא 7 (פרומפט, Guardrails ופלט JSON):** הגדרת הפרומפט, שכבות ההגנה (סף ציון + הנחיית מערכת) והחזרת תשובה מובנית בפורמט JSON.
8. **תא 8 (ניסוי חופשי / ממשק):** הרצת שאלות לבדיקת הבוט (`answer(query)`).

## 3. הגדרת מפתח ה-API (משתני סביבה ואבטחה)
מפתח ה-API של Cohere **אינו** שמור בתוך קוד המחברת או בקבצים המצורפים:
* **בסביבת ההרצה באתר הקורס:** יש להדביק את המפתח בשדה הייעודי "מפתח Cohere" בראש העמוד לפני הרצת התאים.
* **בסביבת Google Colab:** יש להגדיר את המפתח תחת לשונית **Secrets** (סמל המפתח בסרגל הצד) בשם `COHERE_API_KEY` ולאפשר גישה למחברת (`Notebook access`).
